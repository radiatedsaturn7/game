# Laughing in the Abyss

This is a console-based, cooperative strategy game for two players. Rob and Cait explore a surreal 5x5 grid while managing Health, Morality and Sanity.

## Running

```bash
python3 main.py
```

On each turn the board and player stats are shown. Use `w`, `a`, `s`, `d` to move, or `trade <item>` when both players are on the same tile.

Every new tile reveals a unique Encounter Card that has a narrative description and a persistent effect when revisited.

Reach the **Final Gate** together with at least 3 Morality and Sanity to win. If either player's Sanity or Morality drops to 0, the game is lost.
